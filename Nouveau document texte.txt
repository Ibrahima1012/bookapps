# BookApp - Application Angular + Spring Boot

Une application web complète pour gérer des livres avec authentification JWT, développée avec Angular (frontend) et Spring Boot (backend), utilisant MySQL pour la base de données.

---

## 🔧 Technologies utilisées

- **Frontend** : Angular
- **Backend** : Java Spring Boot
- **Base de données** : MySQL
- **Authentification** : Spring Security + JWT

## 🚀 Installation et exécution

### 1. Pré-requis

- Node.js et Angular CLI
- Java JDK 17+
- MySQL
- Maven

---

### 2. Configuration de la base de données (MySQL)

Crée une base de données dans MySQL :

```sql
CREATE DATABASE bookapp;
Dans bookapp-backend/src/main/resources/application.properties :

🔐 Authentification JWT
L'application utilise des jetons JWT pour l'authentification :

Inscription : POST /api/auth/register

Connexion : POST /api/auth/login

Les routes sécurisées nécessitent l'en-tête HTTP :

makefile

Modifier

📦 Endpoints backend
Méthode	URL	Description
POST	/api/auth/register	Inscription utilisateur
POST	/api/auth/login	Connexion utilisateur
GET	/api/books	Liste des livres (auth)
POST	/api/books	Ajouter un livre (auth)
PUT	/api/books/{id}	Modifier un livre (auth)
DELETE	/api/books/{id}	Supprimer un livre (auth)
